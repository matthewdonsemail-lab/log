# Quick Start

You can be from zero to a live listening dashboard in about five minutes.

## 1. Pick your platforms

On the [onboarding screen](http://localhost:3000/onboarding), pick the platforms your customers talk on:

- **Facebook** — groups and public posts
- **X** — public posts and reply threads
- **Reddit** — threads in the communities you care about

Tap a platform card to select it, then hit **Continue**.

## 2. Install the Chrome extension

Grab it from the [Chrome Web Store](https://chromewebstore.google.com/) — or build it from [GitHub](https://github.com/) if you'd rather self-host and hack on the source.

<Callout type="warning">
The extension only captures signals while you're signed in and browsing the platform it's attached to.
</Callout>

## 3. Paste your tokens

For each platform you picked:

1. Open the ListeningKit extension in Chrome.
2. Navigate to the platform (e.g. `reddit.com`) and make sure you're logged in.
3. Copy the cookie token the extension shows you.
4. Paste it into the matching field and hit **Save tokens**.

Your token is your login for that site. ListeningKit encrypts it on the server and never shows it again or sends it to your browser. See the [Guide](/docs/guide/using-listeningkit) for the current steps.

## 4. Watch it cluster

Your signals land on the dashboard almost immediately and start clustering by topic. Open any cluster to see volume, tone, and the raw posts behind it.
