Each screen has a `--json` subcommand and an MCP tool (consoleStart … consoleSettings) and reads one loader in src/console/<page>. `log console --web` serves the built site from a loopback-only Bun server (src/console/web, default port 7338) that answers /api/console/* from the same loaders, injects `window.logConsoleMode = "local"` and answers /api/console/mode; the site then skips the sign-in and team redirects and reads the local endpoints on Start, Connections, Usage, AI clients and Settings, with Teams and Subscription showing the local line.
