# API

Programs read your ListeningKit data with an **API key** made on the dashboard's **API** tab. The API is **read-only**: a key can read your plan, your phrases and your matches, and cannot change anything.

```bash
curl "https://<your deployment>.convex.site/api/v1/matches?limit=5" \
  -H "Authorization: Bearer lk_api_..."
```

- Everything about keys, endpoints, paging, limits and errors is in [The API](/docs/guide/api).
- The earlier mock API this page used to describe is kept as the [Legacy mock API](/docs/api-reference).
